# История изменений Blank

## 0.1.18

### Русский

- Snad: Reforged обновлён до 0.1.2. Этот выпуск поддерживает Minecraft 26.1–26.3 на NeoForge.

### English

- Updated Snad: Reforged to 0.1.2, which supports Minecraft 26.1 through 26.3 on NeoForge.

## 0.1.17

### Русский

- NeoForge обновлён с 26.3.0.115 до 26.3.0.118 для Minecraft 26.3.

### English

- Updated NeoForge from 26.3.0.115 to 26.3.0.118 for Minecraft 26.3.

## 0.1.16

### Русский

- Добавлен Snad: Reforged 0.1.1. Snad и Red Snad ускоряют рост тростника и кактусов по импульсам редстоуна до 16 блоков.

### English

- Added Snad: Reforged 0.1.1. Redstone pulses speed up sugar cane and cactus growth on Snad and Red Snad up to 16 blocks.

## 0.1.15

### Русский

- Возвращён Disenchant Anvil 26.0.2 с исправленной регистрацией конфига для NeoForge 26.3.

### English

- Restored Disenchant Anvil 26.0.2 with fixed config registration for NeoForge 26.3.

## 0.1.14

### Русский

- Отключён Disenchant Anvil 26.0.2, который мешал запуску на NeoForge 26.3. Для снятия зачарований доступен Disenchanting Table.

### English

- Removed Disenchant Anvil 26.0.2 to fix startup on NeoForge 26.3. Disenchanting Table remains available.

## 0.1.13

### Русский

- Добавлены Integrated Dynamics 1.33.4, его зависимость Common Capabilities 2.11.8 и Disenchant Anvil 26.0.2.

### English

- Added Integrated Dynamics 1.33.4, its dependency Common Capabilities 2.11.8, and Disenchant Anvil 26.0.2.

## 0.1.12

### Русский

- Curios API обновлён до 17.0.2 для Minecraft 26.3.

### English

- Updated Curios API to 17.0.2 for Minecraft 26.3.

## 0.1.11

### Русский

- Обновлены Puzzles Lib до 26.3.19, Sophisticated Core до 1.5.43.2503 и Sophisticated Storage до 1.5.135.2247.

### English

- Updated Puzzles Lib to 26.3.19, Sophisticated Core to 1.5.43.2503, and Sophisticated Storage to 1.5.135.2247.

## 0.1.10

### Русский

- Добавлен e4all 2.3.0. Хост может открыть одиночный мир для друзей, в том числе для игроков с локальными профилями Blank Launcher.

### English

- Added e4all 2.3.0. Hosts can open a single-player world to friends, including players using local Blank Launcher profiles.


## 0.1.9

### Русский

- Добавлены Energized Power, GeOre, DimStorage, Easy Piglins, Just Zoom и Remove Reloading Screen.
- Включены библиотеки EdivadLib и Konkrete. Добавлены общие и клиентские конфиги новых модов.

### English

- Added Energized Power, GeOre, DimStorage, Easy Piglins, Just Zoom, and Remove Reloading Screen.
- Included EdivadLib and Konkrete, along with shared and client configuration files for the new mods.

## 0.1.8

- Удалён AI Improvements. Из сборки убраны оставшиеся конфиги AI Improvements и Energy Control.
- Из поставляемых файлов JEI убраны старые ссылки на Energy Control. Изменённая игроками история поиска сохраняется при обновлении.

## 0.1.7

- Mindful Darkness получил точные исключения для шести значков полоски голода и текстуры оверлея AppleSkin.

## 0.1.6

- Из затемнения Mindful Darkness исключены сердца Minecraft и Overflowing Bars. Добавлено первое исключение для значков голода.

## 0.1.5

- Добавлены Accelerated Decay, Additional Enchanted Miner, библиотека Scalable Cat’s Force и CC: Tweaked 1.122.0 для NeoForge.
- Удалён Energy Control.

## 0.1.4

- Для новых профилей добавлены настройки звука из CurseForge. Общая громкость около 24%, музыка выключена. Настройки существующих профилей сохраняются при обновлении.

## 0.1.3

- Для новых профилей включены русский язык, шрифт Faithful 32x, шейдер Complementary Unbound r5.10 и настройки графики из CurseForge.

## 0.1.2

- Первый публичный релиз Blank для Riven. Minecraft 26.3, NeoForge 26.3.0.115 и 110 модов, включая пять изменённых JAR.
