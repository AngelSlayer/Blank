# Blank

Сборка Minecraft 26.3 для NeoForge 26.3.0.115.

## Установка через Riven

1. Установите [Riven 1.3.2](https://github.com/BX-Team/Riven/releases).
2. Добавьте сборку по [ссылке на стабильный канал](https://angelslayer.github.io/Blank/channels/stable.json).
3. Выберите **Blank (1)** в библиотеке Riven и нажмите **Играть**. Riven проверяет обновления перед запуском.

В новых профилях включены русский язык, шрифт Faithful 32x и шейдер Complementary Unbound.
